# ⛅ תחזית מזג אוויר בישראל — שרת MCP

<div dir="rtl">

`Protocol: MCP` &nbsp;|&nbsp; `Python 3.11+` &nbsp;|&nbsp; `License: MIT` &nbsp;|&nbsp; `Status: Active ✅`

**פרויקט לימוד מעשי בפיתוח MCP (Model Context Protocol)** — סוכן חכם (Agent) מבוסס LLM, המסוגל לאחזר תחזית מזג אוויר עדכנית לערים בישראל ובארצות הברית, ולהשיב עליה בשפה טבעית וחופשית בממשק צ'אט טרמינלי.

</div>

---

## 🎯 מטרת הפרויקט

<div dir="rtl">

לבנות שרת MCP ייעודי, ה"מקנה" ל־LLM יכולת שאינה קיימת אצלו באופן מובנה: אחזור תחזית מזג אוויר עדכנית מאתר ישראלי שאין לו ממשק API רשמי וזמין לציבור.

הסוכן פותר אתגר זה באמצעות שני מקורות מידע משלימים:

| # | מקור | שיטת פעולה | תיאור |
|---|------|-------------|--------|
| 1 | **שרת ישראל** (`weather-Israel`) | אוטומציית דפדפן אמיתי באמצעות **Playwright** | פותח את [weather2day.co.il/forecast](https://weather2day.co.il/forecast), מחפש את העיר המבוקשת, בוחר אותה, ואז מחלץ את תוכן דף התחזית — כדי שה־LLM ינתח אותו בעצמו (גישת **RAG**) |
| 2 | **שרת ארה"ב** (`weather-USA`) | קריאת API רשמית | שולף תחזית והתרעות ישירות דרך ה־API הרשמי של **NWS** (National Weather Service) |

ה־**Host** מהווה את שכבת התיווך המרכזית: הוא מחבר בין כל השרתים ל־LLM (Gemini, באמצעות ממשק ה־API התואם ל־OpenAI), חושף בפניו את כלל ה־Tools הזמינים באופן אוטומטי, ומנהל לולאת שיחה דינמית — שבה ה־LLM עצמו בוחר אילו כלים להפעיל ובאיזה סדר, עד לגיבוש תשובה סופית ומדויקת.

</div>

## 🧩 איך זה עובד (תרשים זרימה)

```text
"משתמש → "מה התחזית בתל אביב?
    │
    ▼
Host  →  LLM (Gemini) בוחר להפעיל Tools
    │
    ▼
(שרת ישראל, בזה אחר זה)
open → enter("תל אביב") → select → get_content
    │
    ▼
LLM (RAG) — חוזר לתוכן התחזית
    │
    ▼
✨ LLM כותב תשובה בשפה חופשית בצ'אט
```

## 🛠️ ארכיטקטורה טכנית

<div dir="rtl">

| רכיב | תפקיד |
|------|-------|
| **Host** | מרכז את השיחה, מחבר בין ה־LLM לשני שרתי ה־MCP, ומנהל את לולאת ה־Tool-Calling |
| **LLM (Gemini)** | מקבל את רשימת ה־Tools הזמינים ומחליט אוטונומית אילו להפעיל, באיזה סדר, ועם אילו פרמטרים |
| **weather-Israel** | שרת MCP שמפעיל Playwright, מדמה משתמש אמיתי בדפדפן, וממיר את תוכן הדף לטקסט הניתן לניתוח |
| **weather-USA** | שרת MCP קליל שמבצע קריאות REST ישירות ל־API של NWS |

## 📝 הערות ולקחים מהפרויקט

<div dir="rtl">

- ההחלטה אילו Tools להפעיל ובאיזה סדר מתקבלת אך ורק על ידי ה־LLM עצמו — לא נכתבה שום לוגיקת שיחה ידנית או נוקשה; הבחירה נעשית באופן דינמי, בזמן ריצה, בהתאם לכוונת המשתמש בפועל.
- כל אחד משני קבצי השרת מתפקד כתהליך (Process) עצמאי ונפרד, ולכן כל מצב פנימי משותף (למשל, מופע הדפדפן הפתוח) שמור אך ורק בתוך השרת הרלוונטי, ואינו משותף בין השניים.
- השילוב בין אוטומציית דפדפן (Browser Automation) לבין קריאת API רשמית ממחיש כיצד ניתן להעניק ל־LLM יכולות "עולם אמיתי", גם כאשר לא קיים מקור מידע רשמי וזמין.

</div>
